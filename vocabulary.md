# Generative AI Vocabulary

This vocabulary contains terms that I learned while researching practical applications of Generative AI.

## 1. Large Language Model (LLM)

A type of AI model trained on large amounts of text. It can understand and generate text and can be used for tasks such as summarization, question answering, and code generation.

## 2. Hallucination

A situation when an AI model generates information that sounds correct but is actually incorrect or was not present in the original data.

## 3. Prompt

An instruction or request that a user sends to an AI model to get a specific result.

## 4. Context Window

The amount of information that an AI model can process at one time. If the input is too large, some information may not fit into the model's context.

## 5. Speech-to-Text

A technology that converts spoken audio into written text. It can be used to create transcripts of meetings, calls, or other conversations.

## 6. Speaker Diarization

The process of separating speakers in an audio recording and identifying which parts of the conversation were spoken by different speakers.

## 7. OCR (Optical Character Recognition)

A technology that recognizes text inside images or scanned documents and converts it into machine-readable text.

## 8. RAG (Retrieval-Augmented Generation)

An approach where an AI system first searches for relevant information in external documents or a knowledge base and then gives this information to the AI model to generate a better answer.

## 9. Embedding

A numerical representation of text or other information. Embeddings can be used to compare pieces of information by their meaning and find similar content.

## 10. Vector Search

A search method that uses embeddings to find information that is similar in meaning instead of searching only for exact words.

## 11. Inference

The process of using an already trained AI model to process new input and generate a result.

## 12. Local AI Model

An AI model that runs on the user's own computer or local infrastructure instead of sending requests to an external cloud service.

## 13. Data Normalization

The process of converting data from different formats into one consistent format so that it can be stored, compared, and processed correctly.

## 14. Structured Output

AI-generated information that follows a predefined structure or format, for example JSON with specific fields instead of normal free-form text.

## 15. Human-in-the-Loop

An approach where a human is still involved in an AI process and can review, verify, or correct the result produced by AI.
